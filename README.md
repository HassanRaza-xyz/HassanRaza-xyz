## 🧠 About

<p align="center">
  <em>AI Engineer & Systems Builder — translating research-grade ML into production-ready intelligent software.</em>
</p>

I'm a final-year **B.S. Artificial Intelligence** student at **KFUEIT** with a practitioner-first mindset. My engineering focus sits at the intersection of **LLM systems**, **retrieval-augmented generation**, and **full-stack AI integration** — designing software that doesn't just run models, but wraps them in reliable, low-latency pipelines that non-technical stakeholders can trust.

Across two internships — **ML Engineering at HexSoftwares** and **AI-integrated full-stack at MercurySols** I've moved from data preprocessing and classification baselines to building end-to-end RAG chatbots, real-time NLP visualizers, and gesture-driven computer vision systems. My product engineering philosophy centers on **accuracy, interpretability, and developer experience**: clean APIs, strict prompt guardrails, and measurable evaluation loops.

Outside AI systems, I contribute on the frontend building React dashboards and async FastAPI backends that make model outputs actionable in production UIs.

<br/>

A production-grade **Retrieval-Augmented Generation (RAG) chatbot** built to deliver context-grounded, hallucination-free responses over custom PDF corpora. Engineered with strict system prompt architecture and optimized semantic retrieval pipelines.

<div align="center">

| Attribute | Detail |
|:---|:---|
| **Stack** | Python · LangChain · Gemini API · Hugging Face Embeddings · ChromaDB |
| **Core Architecture** | RAG with PDF ingestion → chunking → vector embedding → semantic retrieval → grounded generation |
| **Performance** | Optimized chunking strategy for maximal semantic search precision at retrieval time |
| **Reliability** | Strict system prompt guardrails engineered to eliminate hallucinations and enforce factual accuracy |
| **Automation** | Python execution layer enabling natural language → backend system task automation |
| **Impact** | Demonstrates end-to-end LLM system design competency from document ingest to streaming output |

</div>

- Architected the full RAG pipeline: ingestion, chunk optimization, embedding, vector store, retrieval chain, and streaming response layer.
- Implemented Hugging Face embedding models tuned for semantic similarity over domain-specific PDF content.
- Engineered prompt structures with explicit role constraints, citation enforcement, and out-of-scope refusal behaviors.
- Built a Python execution interface enabling users to trigger backend automation tasks directly through natural language.

- Optimized inference pipeline to sustain smooth interaction across varying ambient lighting and hand positioning angles.
